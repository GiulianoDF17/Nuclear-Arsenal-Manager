# Nuclear-Arsenal-Manager

## To set the database (should be done once per teammate)
1. Pull or clone the repository in Visual Studio
2. Open SQL Server Object Explorer from View in the toolbar
3. Make sure you see (localdb)\MSSQLLocalDB and connect to it OR open the SQL files in order and type (localdb)\MSSQLLocalDB in the Server Name and enter
4. Open and run CreateTables. It'll create the database and tables
5. Open and run FillTables.sql

Note: If (localdb)\MSSQLLocalDB does not appear in SQL Server Object Explorer, install SQL Server LocalDB through Visual Studio Installer
